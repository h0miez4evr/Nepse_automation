# NEPSE Data Scraper Agent

An AI-powered agent that scrapes Nepal Stock Exchange (NEPSE) data and updates CSV files with daily trading data.

## Features

- **Top 20 Gainers**: Stocks with the highest percentage price increase
- **Top 20 Turnover**: Stocks with the highest trading volume in NPR
- **Top 20 Volume**: Stocks with the most shares traded
- **Top 20 Transactions**: Stocks with the most individual trades
- **Top 20 Relative Strength**: Stocks outperforming the market average

## How It Works

This agent uses NEPSE's official API with a reverse-engineered WASM-based authentication mechanism:

1. Fetches an access token from NEPSE's `/api/authenticate/prove` endpoint
2. Transforms the token using a WebAssembly module (`css.wasm`) that rearranges token characters
3. Uses the transformed token to access protected data endpoints
4. Calculates relative strength by comparing each stock's performance to the market average

### Relative Strength Calculation

Relative Strength (RS) = Stock % Change - Market Average % Change

A positive RS means the stock is outperforming the market, while a negative RS indicates underperformance.

## Usage

### Basic Usage

```bash
# Scrape today's data
python -m nepse_agent.main

# Scrape data for a specific trading day
python -m nepse_agent.main --date 2083-05-08

# Get top 30 stocks per category
python -m nepse_agent.main --top 30

# Specify custom output directory
python -m nepse_agent.main --output ./my_data

# Show summary of existing data
python -m nepse_agent.main --summary
```

### As a Python Library

```python
from nepse_agent.auth import NepseAuth
from nepse_agent.scraper import NepseScraper
from nepse_agent.csv_manager import CSVManager

# Authenticate
auth = NepseAuth()
session = auth.get_authenticated_session()

# Scrape data
scraper = NepseScraper(session)
data = scraper.get_all_data(limit=20)

# Save to CSV
csv_manager = CSVManager(output_dir="nepse_data")
csv_manager.update_all(data, trading_day="2083-05-08")

# Access individual categories
gainers = scraper.get_top_gainers(limit=20)
turnover = scraper.get_top_turnover(limit=20)
rs_stocks = scraper.get_relative_strength_stocks(limit=20)
```

## Output Files

All CSV files are saved in the `nepse_data/` directory (configurable):

| File | Description | Key Columns |
|------|-------------|-------------|
| `nepse_top20_gainers.csv` | Top 20 gaining stocks | symbol, percentage_change, ltp |
| `nepse_top20_turnover.csv` | Top 20 by NPR turnover | symbol, turnover_npr, closing_price |
| `nepse_top20_volume.csv` | Top 20 by shares traded | symbol, shares_traded, closing_price |
| `nepse_top20_transactions.csv` | Top 20 by trade count | symbol, total_trades, last_traded_price |
| `nepse_top20_relative_strength.csv` | Top 20 relative strength | symbol, relative_strength, percentage_change |

Each CSV file contains:
- `trading_day`: Date of the trading session (YYYY-MM-DD)
- `rank`: Rank of the stock in its category (1-20)
- Data columns specific to each category

## Technical Details

### NEPSE API Authentication

The NEPSE website uses a sophisticated anti-scraping mechanism:

1. **Token Generation**: An access token is generated by the server
2. **WASM Transformation**: The token is transformed using a WebAssembly module that rearranges characters based on salt values
3. **Salter Header**: The transformed token is sent as `Authorization: Salter <token>`

This agent replicates the browser's JavaScript transformation logic in Python using the `wasmtime` library to execute the same WASM module.

### API Endpoints Used

- `/api/authenticate/prove` - Get authentication token
- `/api/nots/top-ten/top-gainer?all=true` - All gaining stocks
- `/api/nots/top-ten/top-loser?all=true` - All losing stocks
- `/api/nots/top-ten/turnover?all=true` - All stocks by turnover
- `/api/nots/top-ten/trade?all=true` - All stocks by volume
- `/api/nots/top-ten/transaction?all=true` - All stocks by trades
- `/api/nots/nepse-data/market-open` - Market status
